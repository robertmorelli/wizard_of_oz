How this was run

Every Benchmarks Game port in benchmarks/bg was built with its own toolchain, then passed through Binaryen's wasm-opt (version 128) twice: once with -O3, once with -Oz, with every feature d8 ships enabled. JavaScript has no wasm and is left out. The four utu build modes (fast, fastUnsafe, small, smallUnsafe) and the tuned and host variants share the utu color; hover a dot for its mode.

The C, C++, Rust and AssemblyScript toolchains already run Binaryen or LLVM at full strength, so a second pass changes little there. Dart, Kotlin and MoonBit were optimized without closed-world mode. Run-to-run noise in d8 is about 1–2%.
