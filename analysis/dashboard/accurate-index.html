How this was measured
Levels
O3 = speed build. Os/Oz = size builds. Rust opt-level 3/s/z, Swift -O/-Osize, Zig ReleaseFast/ReleaseSmall (no Os).
Pairs
O3 and the small build run back to back, alternating which goes first. The ratio is taken within each pair, then the median across pairs.
Interval
Bootstrap of the median paired ratio, resampling pairs.
JPL timing
Direct fork/exec/wait4 timer, no hyperfine. Cold drops the page cache first: purge on Mac, drop_caches on x86.
Native timing
Each benchmark's built-in driver: setup untimed, warmups, then the median of the timed runs.
