JPL compilers: O3 vs Os and Oz

Four student JPL compilers, each built at O3, Os and Oz, timed lexing, parsing and typechecking the same 12 MB program. Every dot is one compiler doing one job on one machine: across is its O3 time, up is its Os or Oz time. O3 is meant to be fastest, so a dot in the shaded triangle below the line is the unexpected result.

How this was run

Input: t3.jpl, 12,293,446 bytes, which all four typecheckers accept. Jobs are each compiler's -l (lex and print tokens), -p (parse and print the AST) and -t (typecheck and print) modes, with stdout sent to /dev/null. The three Rust compilers were built with cargo at opt-level 3, s and z plus -C target-cpu=native, keeping each Cargo.toml's other settings. The Zig compiler was built with zig 0.16 at ReleaseFast (shown as O3) and ReleaseSmall (shown as Oz). Each level produced identical output.

Mac: Apple M1 Pro, macOS. x86: AMD Ryzen 5 5600X, Ubuntu 24.04 under WSL2, pinned to one core. Pinned commits: Edward bf9d62c, Stefan (rjplc) d1f18f6, Henry (jpl-rs) 4acfca1.
